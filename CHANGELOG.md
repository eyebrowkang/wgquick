# Changelog

- Initial public release of wgquick.com.

- Bilingual (English/简体中文) UI with strict CSP, offline execution, and copy-to-clipboard helpers.
- Added marketing hero, responsive layout optimised for mobile, new favicon set, and Cloudflare Pages deployment workflow.
